# 🎩 Mafia Party

**One word. One mafia. No mercy.**

A social deduction party game for **3–20 players** — pass-the-phone offline, or **everyone plays from their own home over the internet** (like PUBG — any network, any city).

> ## 🌐 [PLAY NOW — no install needed](https://himansho.github.io/mafia-party/)
> Open on any phone or PC. Create a room, share the 4-letter code, friends join from anywhere in the world.
> Add to Home Screen for the full app experience (PWA).

> ### 📥 [Download the Android APK (v1.0)](https://github.com/Himansho/mafia-party/releases/download/v1.1/mafia-party-v1.1.apk)
> Standalone app with offline pass-the-phone mode. Online rooms work over the internet via Supabase cloud.

- 🕵️ **One secret word**, one mafia who *doesn't know it*
- 🎭 Mafia sees **4 suspects** (the word + 3 decoys) and must blend in
- 🗣️ Everyone gives **one-word clues** → discussion → **vote**
- ⚖️ Strict majority catches the mafia — but the mafia gets a **final guess** to steal the win
- ☁️ **Cloud rooms** (Supabase Edge Function, Mumbai region) — server-authoritative, the secret word never leaves the server
- 🔉 Sound effects & confetti, zero assets — everything synthesized in code
- 📦 **Zero dependencies** — pure HTML/CSS/JS + a single-file Node server (for LAN play)

## 🎮 How to play

1. **Deal** — one player picks the player count (3–20), names, and a topic: 🎬 Movies · 🚀 Space · ⚽ Sports · 🎭 Actors · 🌸 Anime · 🎲 Mix
2. **Reveal** — pass the phone around (or tap on your own device online). One random player sees **🔴 MAFIA** — they get 4 suspect words but not the real one. Everyone else sees the secret word.
3. **Clues** — in speaking order, each player says **one word** related to the secret. Too obvious and the mafia catches on; too vague and you look suspicious.
4. **Discussion** — argue! Who sounded like they were guessing?
5. **Vote** — majority rules. Tie or no majority → nobody dies, new clue round.
6. **Win conditions**
   - ⚖️ Mafia voted out → **final guess**: pick the real word from 6 options. Wrong = civilians win, right = mafia steals the win!
   - 🩸 Last two standing → **mafia wins**
   - 🙊 Someone blurts the word → **mafia wins instantly**

## 🌐 Online architecture (cloud)

- **Game server:** Supabase Edge Function (`mafia-room`) in Mumbai — server-authoritative; the secret word never leaves the server
- **Transport:** HTTPS POST actions + 2s polling for state sync — works through any firewall, no WebSockets needed
- **Hosting:** GitHub Pages (CDN, free, global) — `tools/build-web.js` injects the function URL at build time
- **Rooms:** 4-letter codes in a Postgres table, realtime replication available

## 🏠 LAN server architecture (optional)

- **Transport:** SSE (Server→client push) + plain `POST` (client→server)
- **Authority:** same game logic; each client receives only its own `playerView`
- **Rooms:** 4-letter codes, 2h idle TTL, host migration on disconnect

## 📱 PWA

Installable (Add to Home Screen), offline-capable via service worker, portrait-first responsive design. Icons generated procedurally by `tools/gen-icons.js` — no binary assets in the repo.

## 🎨 Design language

Dark noir (`#0b0e17`) + gold (`#e8c05a`), Georgia serif titles, red accents for the mafia. Card-flip reveals, timer rings, animated confetti. Haptics + sound toggleable in settings.
